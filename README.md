# somruge.github.io

Personal website, deployed via GitHub Pages. Live at: https://somruge.github.io

Built from the APSF specification in
[`Structure/projects/Portfolio/spec`](https://github.com/somruge/Structure/tree/main/projects/Portfolio/spec)
(start with `00-master-spec.md`, then `39-development-handoff.md`).

## Files

- `index.html`: the page. `credits.html`: credits, licences and the privacy note.
- `assets/css/site.css`: design tokens and styles (light/dark via `prefers-color-scheme`, plus a toggle).
- `assets/js/theme.js`: applies the saved theme before first paint. `site.js`: nav, theme toggle, scroll reveal. `game.js`: Balloon Pop.
- `assets/fonts/`: self-hosted Manrope and Source Sans 3 (SIL OFL 1.1, licence files included).
- `assets/brand/`: the turtle logo (animated and still). `assets/icons/`: favicon and touch icon.
- `og-image.png`: social preview, generated by `scripts/og.mjs`.
- `robots.txt`, `sitemap.xml`, `.nojekyll`.

## Working on it

```bash
npm install
npm run dev        # http://localhost:8080
npm run build      # rewrites ?v= on assets to content hashes (run after changing CSS/JS)
npm run test:e2e   # Playwright + axe, one worker
```

There's no bundler: GitHub Pages serves the repository as-is. `npm run build` replaces the old
hand-bumped `?v=N` cache-busting.

Placeholder content awaiting the owner is marked with `data-placeholder` (and shown with a dashed
outline). The site must have none before it goes public.

Browsers for the tests need system libraries. Once per machine:
`sudo npx playwright install-deps chromium webkit`.
